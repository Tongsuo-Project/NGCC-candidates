# Galas optimized implementation

This directory contains the x86-64 optimized implementation for the NGCC
submission of the Galas signature scheme.

The code is derived from the FAEST/Galas optimized code base and keeps the
same SIMD-oriented architecture, while instantiating the Galas OWF and the
Galas VOLEitH/QuickSilver relation. The submitted build uses the NGCC
auxiliary wrapper for hash/XOF/DRNG functionality.

## Supported instances

The optimized implementation supports the same eight instances as the
reference implementation:

```text
Galas-160S  Galas-160F
Galas-256S  Galas-256F
Galas-384S  Galas-384F
Galas-512S  Galas-512F
```

## Building

The Meson project is configured for an optimized release build by default:

```bash
meson setup build --buildtype=release -Doptimization=3
ninja -C build
```

For a fresh benchmark build with link-time optimization:

```bash
meson setup build_bench --buildtype=release -Doptimization=3
ninja -C build_bench galas_bench
./build_bench/galas_bench all 100
```

The current optimized target is x86-64 with AVX2. The build enables AVX2,
AES-NI, PCLMULQDQ, link-time optimization, native tuning, and frame-pointer
omission for the performance-optimized profile.

## Tests and KAT verification

```bash
ninja -C build galas_sign_test galas_verify_kat
./build/galas_sign_test all
./build/galas_verify_kat Galas-256S < ../../kat/galas-256s.txt
```

The KAT verifier accepts the files generated by the reference implementation,
so it is used to check reference/optimized compatibility. Repeat the last
command with the desired instance label and KAT file, for example
`Galas-160S < ../../kat/galas-160s.txt`.

## Notes

This directory intentionally does not include Meson build directories or
compiled binaries in the submission package. Rebuild them locally from the
source files above.
