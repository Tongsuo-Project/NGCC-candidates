gen_params.py -- SHUTTLE derived constants (reproducible)

Each value is a closed-formula function of the PRIMARY (N, Q,
alpha_b, alpha_h) constants of tab:suf-parameters.  Assertions:
  ZETA^n == -1 mod q,  ZETA^{2n} == 1 mod q,  n*NINV == 1 mod q,
  H_h integer,  2^DQ_BITS >= Q,  DS_BITS/DE_BITS == formula.

=== SHUTTLE-128  (n=256, q=15361, alpha_b=2, alpha_h=1024) ===
  DQ_BITS = ceil(log2 15361)              = 14
  BQ      = ceil(14/8)                  = 2
  DB_BITS = ceil(log2 ceil(15361/2))    = ceil(log2 7681) = 13
  HH      = 2(15361-1)/1024           = 30   (NON-power-of-2: decode must range-check, never mod)
  DH_BITS = ceil(log2 30)              = 5
  ZETA    = smallest primitive 2n-th root    = 98   (ZETA^256 = -1 mod 15361, order exactly 512)
  NINV    = pow(256, -1, 15361)           = 15301   (256*15301 mod 15361 = 1)
  DN_BITS = ceil(log2 256)              = 8
  BN      = ceil(8/8)                  = 1
  cross-check: DS_BITS = ceil(log2(2*9+1)) = 5 (OK), DE_BITS = ceil(log2(2*10+1)) = 5 (OK)
